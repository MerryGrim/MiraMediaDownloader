# Руководство пользователя

[Русский](../README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md)

Подробные инструкции на русском. Краткое руководство на английском и китайском находится в соответствующем README.

## Быстрый запуск

1. Запустите установщик или распакуйте переносимый ZIP в удобное место. В основной папке один файл запуска — **`MiraMediaDownloader.exe`**. Для переносимого варианта нужна **вся папка** `MiraMediaDownloader`, включая служебную папку `runtime`; один EXE отдельно не работает. Установщик содержит Python, Qt и файлы Mira. Общий системный Microsoft Visual C++ x64 Runtime проверяется отдельно, как описано ниже.
   Переносимый выпуск распаковывайте в новую папку, чтобы рядом не оставались служебные EXE и библиотеки прежней версии. История находится в выбранной коллекции, сохранённый вход — в данных текущего пользователя Windows.
2. Откройте Mira Media Downloader через ярлык установщика или `MiraMediaDownloader.exe` из распакованной папки. Отдельная установка Python не требуется; Mira устанавливается для текущего пользователя. Если в Windows отсутствует Microsoft Visual C++ x64 Runtime, его отдельный официальный установщик может запросить подтверждение администратора. Сборка рассчитана на Windows 10 (1809 и новее) / Windows 11 x64; это [поддерживаемые платформы Qt 6.11](https://doc.qt.io/qt-6.11/windows.html).
3. Выберите **X** или **Pixiv** вверху окна и вставьте ссылку автора: `https://x.com/имя_автора`, `https://twitter.com/имя_автора` или `https://www.pixiv.net/users/ЧИСЛОВОЙ_ID`. Корректная вставленная ссылка сама переключает платформу. Выбор Pixiv включает экспериментальный адаптер; отдельный флажок не требуется.
4. Выберите папку картинок. При доступном диске D приложение предлагает папку на D; путь можно изменить.
5. Нажмите **«Войти в X»** или **«Войти в Pixiv»** для выбранной платформы. Откроется настоящая страница соответствующего сайта. Войдите обычным способом, при необходимости пройдите проверку и 2FA. Для Pixiv сначала настройте видимость содержимого на самом сайте — подробности ниже. Нажмите **«Сохранить вход»**, когда вход будет подтверждён. Отдельный браузер, расширение и экспорт файла не требуются.
6. При необходимости откройте кнопку **«Все даты»**, выберите период и нажмите **«Применить»**. Затем нажмите **«Найти и скачать»**. Приложение за один обход находит картинки, считает их и сразу сохраняет. Предварительный подсчёт не требуется. Включённый режим «Только новые» подходит для последующих запусков того же автора.

В основном окне находятся платформа, ссылка, вход, папка, период и запуск. **«Картинки»**, **«История»** и **«Журнал»** — три вкладки с результатами, прежними заданиями и сообщениями. Источники авторизации из браузера/файла, задержки запросов и локальный выход находятся в отдельном окне **«Дополнительно»**. При ручной смене платформы несовместимая ссылка очищается; папка и выбранный период сохраняются.

Вверху окна кнопка с глобусом и подписью **RU / EN / 中文** открывает выбор **Русский / English / 简体中文**. Рядом кнопка с луной или солнцем переключает **светлую и тёмную тему**. Язык и оформление меняются сразу и сохраняются для следующего запуска. Переведены нативные окна, подписи, помощь и сообщения Mira; названия платформ, пути и исходные сообщения сайтов могут оставаться без перевода. Тема охватывает основное окно, календари, списки и нативные элементы окна входа. Веб-страницы платформ используют собственное оформление.

Основная кнопка **«Найти и скачать»** выполняет поиск, подсчёт и сохранение за один обход: загрузка начинается по мере нахождения изображений, счётчик растёт, окончательное число известно в конце полученной выдачи. Отдельная кнопка **«Найти и посчитать»** нужна только для необязательного подсчёта без скачивания оригиналов. После неё основная кнопка запускает новое задание; результат может измениться между обходами. Превью показывает **уже сохранённые** изображения: отдельного сетевого обхода миниатюр нет. В журнале видны этапы работы и ошибки. Картинки из одного поста сохраняются отдельными файлами с номером изображения; видео не скачиваются.

## Системный компонент Windows

Нужен **Microsoft Visual C++ v14 Runtime x64 версии 14.44.35211 или новее**.
Обычно он уже установлен другими Windows-приложениями. Установщик Mira проверяет
его: при наличии продолжает обычную установку; при отсутствии предлагает
отдельную загрузку с официального сервера Microsoft и запускает стандартное
окно установки компонента по вашему согласию. Условия Microsoft и возможное
подтверждение Windows показываются самим установщиком компонента.
После этого Mira продолжает установку. При отказе или ошибке изменения
приложения не начинаются; запуск можно повторить после установки компонента.

Для переносимой версии действует та же предпосылка. Если её нет, Mira покажет
понятное сообщение до запуска основного окна. [Официальная страница Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)
содержит установщик x64; отдельные DLL из случайных сайтов не нужны.
Библиотеки Microsoft не вложены в GPL-архив приложения. С готовым системным
компонентом установка Mira и запуск работают без скачивания зависимостей.

## Вход и границы доступа

Основной способ — **вход в приложении**. Для X открывается `https://x.com/i/flow/login`, для Pixiv — `https://accounts.pixiv.net/login` с возвратом на `https://www.pixiv.net/`. Кнопка и статус относятся к выбранной платформе; корректная ссылка синхронизирует выбор, а сессии X и Pixiv хранятся раздельно. Данные вводятся в настоящую веб-страницу сайта внутри Qt WebEngine. Mira не подставляет и не перехватывает содержимое полей пароля или 2FA. Строка адреса показывает текущий HTTPS-адрес без служебных параметров. Переходы главного окна разрешены только на точные домены соответствующей платформы. Дополнительные окна и скачивание файлов в окне входа заблокированы. Внешние страницы Google/Apple и другие сторонние способы входа не поддерживаются; используйте обычный вход сайта. Проверки CAPTCHA выполняются вручную в разрешённом виджете самого сайта.

Во встроенном окне используйте **вход по паролю**, вручную проходя CAPTCHA и подтверждение 2FA, если сайт их требует. **Ключи доступа через Windows Hello здесь не поддерживаются**: нативная проверка Windows отключена, чтобы приложение корректно завершалось после посещения формы Pixiv. Если аккаунту необходим такой ключ, войдите в собственном браузере и выберите его сессию как источник авторизации в Mira.

Временный браузерный профиль работает в памяти: его cookies и веб-кэш не сохраняются на диск. После **«Сохранить вход»** Mira сохраняет только необходимые cookies: X — `auth_token` и `ct0`, Pixiv — `PHPSESSID`. Они защищены Windows DPAPI текущего пользователя и используются в прямых HTTPS-запросах к соответствующей платформе; разработчик, аналитические сервисы и посредники их не получают. Пароль в хранилище не записывается. Секреты не включаются в QSettings, историю скачивания, файлы заданий или архив приложения. Журнал очищается от известных секретных значений, но перед передачей отчёта всё равно просмотрите его.

Для страниц входа запрашивается **английский язык** независимо от языка Mira. Окончательный язык формы выбирает сайт с учётом своих правил и аккаунта, поэтому это предпочтение, а не гарантия перевода каждой страницы. Язык Mira выбирается отдельно кнопкой с глобусом.

**Для Pixiv одного `PHPSESSID` недостаточно:** сайт выдаёт его и гостям. После входа Mira автоматически проверяет аккаунт обычным запросом только для чтения к самому Pixiv. Проверка работает на английской главной странице, страницах автора и в настройках; она не зависит от разметки главной страницы. В приложение возвращается только результат «да/нет», без чтения полей формы или пароля. Кнопка **«Проверить вход»** повторяет проверку вручную, а **«Сохранить вход»** запрашивает свежее подтверждение перед сохранением. При смене страницы или сессии прежний результат отменяется. Перед каждым авторизованным заданием, в том числе при импорте браузера или файла, worker ещё раз проверяет вход. Гостевая, истёкшая или неподтверждённая сессия останавливает обход с ошибкой входа. Явно выбранный режим «Без авторизации» остаётся отдельным ограниченным сценарием.

Сохранённый вход относится к текущей учётной записи Windows и автоматически применяется при следующем запуске. **«Выйти из X»** / **«Выйти из Pixiv»** удаляет только локальную сессию выбранной платформы; вход другой платформы остаётся. Для завершения сессии на стороне сайта используйте его настройки безопасности. Закрытие или отмена окна входа не заменяет ранее сохранённый вход. Отдельный аккаунт для каждого автора не нужен: один ваш аккаунт платформы просматривает доступные ему профили.

Статус сохранённого входа подтверждает наличие локальной сессии, а не её бессрочную действительность на сервере. Платформа может потребовать повторный вход, ограничить встроенный браузер или отклонить автоматические запросы. Приложение не обходит такие ограничения. При ошибке авторизации повторите вход в выбранную платформу; если сайт не разрешает такое окно, доступны прежние способы ниже.

Это обычный вход на сайты, **не OAuth** и не одобрение приложения платформами. Официальная интеграция X API потребовала бы отдельно зарегистрированного приложения и его настроек; в эту сборку она не входит. Мобильный OAuth/refresh token Pixiv не используется.

### Дополнительный способ: собственный браузер без расширений

1. Откройте X или Pixiv в **своём** Firefox, Chrome, Edge или Brave и войдите обычным способом. Убедитесь, что нужный профиль автора и его работы доступны.
2. В Mira откройте **«Дополнительно»**, выберите источник «Из браузера», затем браузер и его профиль. Если профилей несколько, нужен тот, где выполнен вход в соответствующую платформу. «Обновить» перечитывает список профилей; чтение cookies происходит при запуске выбранной задачи.
3. Для Firefox выполните вход в обычной вкладке **вне контейнеров**: поддерживается только контейнер по умолчанию. Приватные вкладки и сессии других контейнеров не импортируются.
4. Нажмите «Найти и посчитать» или «Найти и скачать». Перед каждым запуском Mira заново читает сессию из выбранного браузера. После повторного входа в браузере не нужно создавать новый файл.

Чтение работает под той же учётной записью Windows, которой принадлежит профиль браузера. Читаются только cookies выбранной платформы: для X — `auth_token` и `ct0`, для экспериментального Pixiv — `PHPSESSID`. База браузера открывается только для чтения; копия всей базы и экспорт cookies не создаются. Не выбирайте чужой профиль и не передавайте файлы сессии другим людям.

**Chrome, Edge и Brave:** современные версии Windows-браузеров могут использовать App-Bound Encryption (`v20`). Mira не обходит эту защиту: при недоступном ключе, заблокированной базе или неподдерживаемом формате показывает ошибку. Поддерживаются только доступные текущему пользователю прежние форматы Windows DPAPI и `v10`/`v11`. Не требуются права администратора; приложение не завершает браузер и не внедряется в него. Для защищённой Chromium-сессии войдите в нужную платформу в Firefox и выберите Firefox в Mira, либо используйте собственный Netscape-файл как запасной вариант. При занятой базе можно самостоятельно закрыть браузер и повторить запуск; это не снимает App-Bound Encryption.

Если выбранная сессия отсутствует или истекла, задача завершается с понятной ошибкой авторизации. Автоматического переключения на другой источник, другой профиль, другую сессию или анонимный вход нет. X часто требует действующую пользовательскую сессию даже для публичного профиля.

### Запасной вариант: собственный cookies.txt

В окне **«Дополнительно»** источник «Из файла cookies.txt» принимает Netscape `cookies.txt`, экспортированный локально доверенным инструментом из вашей сессии. Выберите файл в поле рядом. Сам файл содержит действующую сессию: храните его как пароль, не загружайте в интернет, не вкладывайте в отчёты и архив проекта. Путь к нему не запоминается между запусками. Этот вариант можно использовать, если прямое чтение браузера недоступно. «Без авторизации» — отдельный явный выбор; X часто отклоняет такой запрос даже для публичного профиля.

Приложение не подбирает пароль, не обходит CAPTCHA, платную подписку, блокировку аккаунта или ограничения авторизации.

Это независимый клиент, не официальный продукт X или Pixiv. Адаптер X использует поддерживаемый gallery-dl разбор веб-интерфейса, а не официальный X API. Поддержка сайта в gallery-dl не означает разрешение платформы на любой способ автоматизации: используйте приложение в рамках доступных вам прав и правил площадки.

«Все доступные» означает все изображения, которые платформа вернула в текущем обходе. Удалённые публикации, приватные материалы без разрешения, скрытые результаты, ограничения глубины выдачи и временные сбои могут сделать подборку неполной. Статус завершения означает завершение полученной выдачи, а не доказанную полноту архива автора. При изменениях X может потребоваться обновление приложения и gallery-dl.

## Качество, даты и повторы

- Для X сначала запрашивается исходный размер `orig`. Если сервер вернул именно 404, пробуются предложенные платформой меньшие варианты в порядке качества. При 401/403/429 приложение останавливается и не использует смену размера для обхода доступа. Для Pixiv запрашивается явно возвращённый оригинал. Изображения не увеличиваются искусственно и не перекодируются.
- Обрабатываются все изображения поста, а не только первое. Чужие картинки из репостов и развёрнутых цитат, аватар и баннер исключены; собственные вложения автора в посте с цитатой сохраняются.
- Обе даты включены. День трактуется по **UTC**: «по 14.10.2026» включает время до 23:59:59 UTC этого дня. Это может отличаться от локального дня в браузере.
- «Только новые» сверяет сохранённую историю с наличием и размером файла. Повторный поиск всё равно обращается к платформе, но сохранённые картинки повторно не скачивает. Чтобы проверить/восстановить файлы, снимите этот флажок: изображения будут скачаны и проверены заново.
- После скачивания вычисляется SHA-256. Одинаковое содержимое в пределах одной папки автора не создаёт второй файл. Счётчик найденных элементов может быть выше числа файлов из-за таких повторов и фильтров.

Кнопка периода открывает отдельное окно **«Период загрузки»**. Выберите «Все даты» либо «Выбрать период» и отметьте начало «С», окончание «По» или обе границы. Одна граница ограничивает только соответствующую сторону; одинаковые даты означают один день UTC. **«Применить»** переносит выбор в задание, **«Отмена»**, Escape или закрытие окна сохраняют прежний период. Начало позже окончания не принимается. Подпись кнопки показывает действующий период.

Нажмите всю кнопку с датой, чтобы открыть календарь. В нём доступны крупные кнопки предыдущего/следующего месяца, переход на год и **«Сегодня»** по UTC. Нажатие дня выбирает дату и закрывает календарь; перелистывание или закрытие календаря без выбора дня не меняет дату. Окончательно период применяется только кнопкой **«Применить»** родительского окна. Интервал запросов в «Дополнительно» можно ввести с клавиатуры или изменить отдельными кнопками **− / +**.

## Пауза, остановка и продолжение

«Пауза» запрещает начало следующих запросов и приостанавливает запись между блоками файла. Запрос, уже ожидающий ответа сервера, может завершиться только после ответа или тайм-аута; интерфейс остаётся отзывчивым. «Продолжить» возобновляет работу. «Стоп» сохраняет историю завершённых файлов и завершает текущую задачу. При закрытии окна используйте штатную остановку.

После перезапуска вставьте ту же ссылку, выберите **тот же каталог** и запустите с «Только новые». Обход начинается заново с защитой от повторов; сохранение непрозрачного курсора X не обещается. Незавершённое изображение скачивается заново для проверки целостности. Временный `.part` не считается готовой картинкой; конечное имя появляется после проверки формата и атомарного переименования.

Сетевые операции последовательны. Между запросами есть настраиваемая задержка; приложение делает ограниченное число повторов и реагирует на временные ограничения сервера ожиданием/ошибкой. Уменьшать задержку до агрессивных значений не следует. Пауза/остановка во время зависшего соединения может занять до сетевого тайм-аута (10 секунд на соединение, 25 секунд на чтение).

В выбранной папке хранятся:

```text
<ваша папка>/
  X/<числовой ID автора>/...картинки...
  Pixiv/<ID автора>/...картинки...
  .mira/
    history.sqlite3       история, результаты задач, контрольные суммы
    logs/job-<ID>.log     журнал конкретного запуска
    tasks/               временные локальные описания запуска
```

Папка автора называется его числовым ID: смена имени профиля X не создаёт новую папку. Названия файлов смотрите в фактически созданных каталогах. Для переноса истории копируйте всю выбранную папку вместе со скрытым каталогом `.mira` при закрытом приложении. Не редактируйте базу вручную. Удаление `.mira` удаляет историю и требует повторной проверки; изображения остаются на месте. Если выбрать другую папку, её история будет отдельной. Несекретные настройки окна, языка и темы, последний профиль автора, выбранный каталог, источник авторизации, название браузера и путь выбранного браузерного профиля сохраняются стандартным механизмом Qt в пользовательском реестре Windows (`HKEY_CURRENT_USER\Software\Mira\MiraMediaDownloader`). Содержимое cookies и путь к ручному cookies-файлу в этих настройках не сохраняются.

Встроенный вход хранится отдельно от библиотеки, в `%LOCALAPPDATA%\Mira\MiraMediaDownloader\`: X — `x-session.dpapi`, Pixiv — `pixiv-session.dpapi`. Это отдельные файлы, зашифрованные текущим пользователем Windows. Вход и выход Pixiv не заменяют сохранённый вход X. Не переносите эти файлы в архив библиотеки, отчёт или поставку; на другом компьютере/в другой учётной записи войдите заново. Кнопка выхода удаляет локальный файл выбранной платформы. Само содержимое сессии в настройках реестра не хранится.

## Pixiv: вход, видимость работ и экспериментальный адаптер

1. **Сначала настройте видимость содержимого в своём аккаунте на Pixiv.** Откройте [настройки отображения Pixiv](https://www.pixiv.net/settings/viewing) и выберите доступные вам параметры просмотра. Для материалов с возрастным ограничением действуют возраст и правила аккаунта; Mira не меняет эти настройки и не снимает ограничения. Проверьте, что нужные работы открываются на самом сайте. Официальные пояснения: [рейтинги работ](https://www.pixiv.help/hc/en-us/articles/39125149371289-What-are-work-ratings), [возрастные ограничения R-18/R-18G](https://www.pixiv.help/hc/en-us/articles/235585288-I-would-like-to-view-age-restricted-contents-R-18-R-18G).
2. В Mira выберите **Pixiv** вверху окна и вставьте `https://www.pixiv.net/users/ЧИСЛОВОЙ_ID`; корректная ссылка Pixiv также выбирает платформу автоматически. Адаптер помечен экспериментальным. Нажмите **«Войти в Pixiv»** и войдите на странице сайта; в этом окне кнопка **«Настройки показа»** также открывает официальные настройки для ручной проверки. После входа или настройки дождитесь проверки аккаунта, при необходимости нажмите **«Проверить вход»**, затем **«Сохранить вход»**. Настройки относятся к тому аккаунту, с которым вы входите в Mira. Если они менялись в другом браузере, всё равно проверьте, что используется тот же аккаунт.
3. Выберите папку и нажмите **«Найти и скачать»**: поиск, подсчёт и сохранение идут вместе, предварительный обход не нужен. Счётчик считает каждую страницу с доступным оригиналом: работа из пяти картинок даёт пять изображений. Он растёт по мере обхода; число ID публикаций в профиле не равно числу картинок. Если нужен только подсчёт без оригиналов, отдельно выберите **«Найти и посчитать»**.

Адаптер обращается к обычным веб-эндпоинтам Pixiv с локальной сессией пользователя. Перед авторизованным обходом он проверяет вход через `/ajax/user/extra`; гостевая или истёкшая сессия останавливает задачу. Сохраняются явно возвращённые **оригиналы всех доступных страниц иллюстраций и манги**, без замены на размытые миниатюры или увеличения. Если оригинал недоступен, работа/страница пропускается с записью в журнал. Ugoira и видео не скачиваются. Явный режим без авторизации может видеть меньше публикаций; это не подтверждение полноты профиля.



## Если что-то не скачивается

- **Вход не выполнен**: нажмите кнопку входа выбранной платформы, завершите обычный вход на сайте и нажмите «Сохранить вход».
- **Pixiv: «Вход не подтверждён» / кнопка сохранения недоступна**: завершите вход в аккаунт и дождитесь проверки или нажмите «Проверить вход». Проверка входа поддерживает английскую страницу и настройки аккаунта. Гостевой сессии недостаточно. Если сервер не подтверждает аккаунт, доступны собственный браузер и cookies-файл с повторной серверной проверкой.
- **На Pixiv видна только часть работ**: сначала проверьте [настройки отображения](https://www.pixiv.net/settings/viewing) и доступность работ в том же аккаунте на сайте. Mira их не изменяет. Сверьте также даты и журнал пропущенных недоступных оригиналов.
- **Сайт не разрешает встроенное окно / не удаётся войти**: ограничения страницы не обходятся. Можно явно выбрать прежний источник «Из браузера» или собственный файл cookies.txt.
- **Не найдена сессия X при источнике «Из браузера»**: войдите в X в выбранном браузерном профиле. Для Firefox используйте обычную вкладку вне контейнеров, затем повторите запуск.
- **Защищённая сессия Chrome / Edge / Brave**: для App-Bound Encryption прямое чтение недоступно; войдите в нужную платформу в Firefox и выберите его либо подключите собственный cookies-файл.
- **База браузера занята**: самостоятельно закройте браузер и повторите запуск. Mira не закрывает браузер автоматически.
- **Нужна авторизация / 401 / 403**: проверьте доступ к профилю и повторно войдите в нужную платформу тем же выбранным способом. Для встроенного режима нажмите её кнопку входа; при источнике «Из файла cookies.txt» обновите собственный cookies-файл, затем повторите запуск.
- **429 / лимит запросов**: дождитесь окончания ограничения и увеличьте задержку в «Дополнительно»; не запускайте несколько копий для обхода лимита.
- **Нет новых файлов**: проверьте даты, выбранную папку, историю и доступность медиавкладки; результат может быть пустым из-за ограничений платформы.
- **Ошибка каталога**: выберите доступную для записи папку и проверьте свободное место.
- **Файл не является изображением**: приложение не запишет страницу ошибки как JPG; подробность будет в журнале.

Результаты проверки готового приложения указаны в отчёте QA на [странице скачивания](https://github.com/MerryGrim/MiraMediaDownloader/releases/latest). Синтетические проверки не доказывают полноту доступной галереи.
