Qt and Pillow include additional third-party libraries and codecs. See [Qt's module-specific acknowledgments](https://doc.qt.io/qt-6/licenses-used-in-qt.html), the Qt license texts under `licenses/`, and Pillow's complete LICENSE. Qt Core, Gui and Widgets supply the native interface; Qt WebEngine supplies the separate X/Pixiv website login windows and includes the Chromium renderer, resources and locales. Qt WebChannel, Positioning and supporting native dependencies are retained as needed by the supplied bindings and runtime. Native runtime libraries and their notices remain part of their respective projects. In addition to installed package metadata/notices, `licenses/QtWebEngine-attributions/` contains unmodified license, copyright, notice, author and README.chromium files extracted from the official exact Qt 6.11.2 source archive. Its manifest records the archive URL/SHA-256 and each original path and file hash; it is not documentation from a different Qt release. The offline collector is `scripts/collect_webengine_notices.py --refresh --source-archive <qt-everywhere-src-6.11.2.tar.xz>`. Ordinary builds verify the saved snapshot. The unused Qt Virtual Keyboard DLL/plugin/data are excluded. The software OpenGL fallback (`opengl32sw.dll`) retains its Mesa/LLVM notices and upstream source in the dependency companion.


PyCryptodomex is used locally for legacy Chromium AES cookie decryption with a key available through the current Windows user's DPAPI. It does not provide an App-Bound Encryption bypass. Its installed license and metadata are included in `licenses/`; the upstream source is unmodified. Mira's separate built-in X/Pixiv session vaults use the Windows DPAPI API of the current user; Windows itself is not redistributed.
