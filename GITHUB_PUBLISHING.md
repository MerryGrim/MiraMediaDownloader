Репозиторий: https://github.com/MerryGrim/MiraMediaDownloader

Релиз: https://github.com/MerryGrim/MiraMediaDownloader/releases/tag/v1.4.4

Собственный код публикуется под **GPL-2.0-or-later** с дополнительным разрешением
для библиотек в `COPYRIGHT`. Исходный текст GPLv2 находится в `LICENSE`.
Сторонние компоненты сохраняют свои лицензии. Выбор GPLv2 для общей программы,
основание для обязательной зависимости gallery-dl от Requests и условия Qt
описаны в `docs/DEPENDENCY_PERMISSION.md` и `docs/LICENSING.md`.

В Releases публикуются установщик, переносимый ZIP, исходники Mira, отдельный
полный комплект исходников зависимостей и SHA-256. В Windows-пакетах есть
`SOURCE_CODE.txt` с точными ссылками на соответствующие исходники этого релиза.
Qt/PySide закреплён на 6.11.2 с проверенным официальным исходным архивом,
неиспользуемый Qt Virtual Keyboard исключён. Обновления бинарных релизов требуют
повторной проверки состава, исходников, лицензий и реального запуска сборки.

Git содержит код, тесты, исходную графику, скрипты сборки/установки, документацию,
лицензионные тексты, атрибуции и манифесты. Большие исходные архивы зависимостей
предоставляются в Releases. В Git нет готового runtime, cookies, DPAPI-файлов,
профилей браузеров, `.mira`, истории, журналов и пользовательских изображений.
`licenses/** -text` сохраняет исходные байты чужих уведомлений и их SHA-256.

Публикуемое дерево и история проверяются до отправки; секреты не передаются
в адресах Git. Пользователь подтвердил скачивание X и Pixiv в прежних версиях;
тесты агента не включают его реальные аккаунты и не доказывают полноту галерей.
Pixiv сохраняет экспериментальный статус. Скачиваемые изображения и товарные
знаки не получают лицензию GPL от этого приложения.
