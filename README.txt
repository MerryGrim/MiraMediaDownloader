For the portable application, keep the entire extracted folder, including
runtime, and launch MiraMediaDownloader.exe. Python is included. The Microsoft
Visual C++ x64 system runtime is a separate prerequisite; see the user guide.

X is the main platform; Pixiv is experimental. Platform access and history
limits can prevent a complete collection. Saved login sessions stay local.
